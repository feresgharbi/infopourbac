Les sujets du Bac pratique changent chaque année, mais ils s'appuient presque toujours sur les mêmes briques : tester si un nombre est premier, calculer un PGCD, parcourir les chiffres d'un nombre, vérifier un palindrome, convertir en binaire. Voici ces algorithmes de référence, en notation officielle et en Python.

L'essentiel

  • Premier : aucun diviseur entre 2 et n DIV 2.
  • Chiffres d'un nombre : n % 10 puis n // 10.
  • PGCD : algorithme d'Euclide avec le reste a % b.
  • Binaire : restes successifs de la division par 2, lus à l'envers.

1Tester si un nombre est premier

Un entier n ≥ 2 est premier s'il n'est divisible que par 1 et par lui-même. On cherche un diviseur d entre 2 et n DIV 2 ; si on n'en trouve aucun, n est premier.

2Somme des diviseurs et nombre parfait

Un nombre est parfait s'il est égal à la somme de ses diviseurs autres que lui-même : 6 = 1 + 2 + 3 et 28 = 1 + 2 + 4 + 7 + 14.

3PGCD par l'algorithme d'Euclide

Le PGCD de a et b est le plus grand entier qui divise les deux. Euclide remplace (a, b) par (b, a MOD b) jusqu'à ce que b soit nul. Deux nombres sont premiers entre eux si leur PGCD vaut 1.

5Inverse d'un nombre et palindrome numérique

L'inverse de 1234 est 4321. Un nombre est palindrome s'il est égal à son inverse (121, 4554).

6Palindrome sur une chaîne

On compare les caractères des deux extrémités en avançant vers le milieu. C'est l'algorithme donné dans le sujet du Bac pratique 2025.

Astuce pour le Bac
Pour tester un nombre, il suffit de le convertir : palindrome(str(n)).

7Conversions décimal ↔ binaire

Pour écrire n en base 2, on divise n par 2 et on garde les restes, que l'on place à gauche du résultat. Exemple : 13 → 1101.

À savoir
Avec la boucle Répéter, la conversion de 0 donne bien "0". Python propose aussi bin(13), qui renvoie '0b1101', mais au Bac on attend en général l'algorithme.

8Factorielle

n! = 1 × 2 × … × n, avec 0! = 1. C'est un accumulateur de produit : il commence à 1.

À retenir

  • Ces fonctions se combinent : « premier palindrome » = premier(n) and palindrome(str(n)).
  • Chiffres d'un nombre : % 10 et // 10 ; ou conversion en chaîne avec str().
  • Écris chaque brique dans sa propre fonction : c'est la solution modulaire attendue.

Questions fréquentes

Comment tester si un nombre est premier en Python ?
On cherche un diviseur d entre 2 et n // 2. Si aucun d ne vérifie n % d == 0 (et si n ≥ 2), le nombre est premier.
Comment convertir un nombre en binaire sans bin() ?
On divise successivement par 2 et on ajoute chaque reste à gauche d'une chaîne : ch = str(n % 2) + ch, puis n = n // 2, jusqu'à n = 0.
Comment calculer le PGCD de deux nombres en Python ?
Avec l'algorithme d'Euclide : tant que b est non nul, on remplace (a, b) par (b, a % b) ; le PGCD est la dernière valeur de a.
