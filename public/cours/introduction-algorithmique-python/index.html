Un algorithme est une suite finie et ordonnée d'instructions qui permet de résoudre un problème. Au Bac scientifique en Tunisie, on écrit d'abord la solution sous forme d'algorithme, puis on la traduit en Python, le langage officiel de l'épreuve pratique.

L'essentiel

  • Algorithme = la solution écrite en langage structuré, indépendante de tout langage de programmation.
  • Programme = la traduction de l'algorithme dans un langage (ici Python 3).
  • Un algorithme commence par Algorithme Nom, contient les instructions entre Début et Fin, et ses objets sont déclarés dans un TDO.
  • Outils à installer : Python 3, l'éditeur Thonny, les bibliothèques numpy et PyQt5 (avec Qt Designer).

1.1Qu'est-ce qu'un algorithme ?

Algorithme : suite finie et ordonnée d'instructions qui, exécutées dans l'ordre, permettent de résoudre un problème donné.

Tu utilises des algorithmes tous les jours sans le savoir : une recette de cuisine, l'itinéraire pour aller au lycée ou la notice de montage d'un meuble. Chacun décrit des étapes précises, dans un ordre précis, qui mènent à un résultat.

Un bon algorithme a trois qualités :

  • il est fini : il s'arrête toujours après un nombre limité d'étapes ;
  • il est précis : chaque instruction n'a qu'une seule interprétation possible ;
  • il est général : il fonctionne pour toutes les données valides, pas seulement pour un exemple.

1.2De l'algorithme au programme Python

Résoudre un problème en informatique se fait en deux temps : on réfléchit à la solution (l'algorithme), puis on la traduit pour que l'ordinateur puisse l'exécuter (le programme).

Algorithme et programme : les différences
AlgorithmeProgramme
RôleDécrire la solutionFaire exécuter la solution par l'ordinateur
LangageLangage algorithmique (notation officielle)Langage de programmation : Python 3
Exécutable ?Non, il se lit et se vérifie à la mainOui, avec un interpréteur Python
RèglesNotation structurée (Début, Fin, Si, Pour…)Syntaxe stricte : indentation, deux-points, parenthèses

Pourquoi Python ? Sa syntaxe est proche du langage naturel, il est gratuit, il fonctionne sur tous les ordinateurs, et c'est le langage retenu pour l'épreuve pratique d'informatique du baccalauréat tunisien.

1.3La structure d'un algorithme

Tout algorithme suit la même structure : un nom, puis les instructions placées entre Début et Fin. Les objets utilisés (variables, constantes) sont décrits dans un tableau à part : le TDO (tableau de déclaration des objets).

Tableau de déclaration des objets (TDO)
ObjetType / Nature

Remarque que Python n'a ni Début ni Fin : un programme commence à la première ligne et se termine à la dernière. La déclaration des variables n'existe pas non plus : une variable est créée au moment où on lui donne une valeur.

1.5Les bonnes pratiques dès le départ

  • Donne des noms clairs à tes variables : moyenne plutôt que m.
  • Respecte l'indentation (4 espaces) : en Python, elle fait partie de la syntaxe.
  • Écris un commentaire avec # pour expliquer une ligne difficile.
  • Teste ton programme avec plusieurs valeurs, y compris des cas limites (0, valeur négative, saisie vide).
  • Enregistre ton travail souvent.

À retenir

  • Algorithme = solution structurée ; programme = sa traduction en Python.
  • Un algorithme : Algorithme Nom, Début, instructions, Fin + un TDO.
  • Python ne déclare pas ses variables et n'a pas de Début/Fin : l'indentation structure le code.

Questions fréquentes

Quelle est la différence entre un algorithme et un programme ?
L'algorithme décrit la solution dans un langage structuré, indépendant de tout langage informatique. Le programme est la traduction de cet algorithme dans un langage que l'ordinateur sait exécuter, comme Python.
Faut-il savoir lire un algorithme pour le Bac pratique ?
Oui. Certains sujets donnent directement un algorithme (par exemple une fonction Palindrome en 2025) et demandent de l'implémenter en Python. Il faut donc savoir traduire chaque instruction algorithmique.
Quel éditeur utiliser pour programmer en Python au Bac ?
Thonny est l'éditeur le plus utilisé dans les lycées tunisiens : il est simple, installe Python automatiquement et permet d'exécuter le code ligne par ligne.
