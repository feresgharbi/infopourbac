Au Bac pratique, le programme Python est piloté par une interface graphique : une fenêtre dessinée avec Qt Designer, enregistrée dans un fichier .ui, puis chargée en Python avec PyQt5. Un clic sur un bouton lance le module Play, qui lit les saisies, les vérifie, calcule et affiche le résultat.

L'essentiel

  • 3 composants essentiels : QLabel (texte), QLineEdit (saisie), QPushButton (bouton).
  • Chaque composant a un objectName : c'est le nom utilisé dans le code.
  • Lire : windows.nom.text() ; écrire : windows.nom.setText(texte).
  • Relier : windows.bouton.clicked.connect(Play), sans parenthèses après Play.

11.1Qu'est-ce qu'une interface graphique ?

Interface graphique (IHM) : fenêtre qui permet à l'utilisateur d'interagir avec le programme à l'aide de zones de saisie, de boutons et de zones d'affichage, au lieu de la console.

Les composants utilisés au Bac
Composant (widget)RôleMéthodes utiles
QLabelAfficher un texte fixe ou un résultatsetText(ch), text(), clear()
QLineEditSaisir une valeur sur une lignetext(), setText(ch), clear()
QPushButtonDéclencher un traitement par un clicclicked.connect(module)

11.2Créer l'interface dans Qt Designer

  1. Ouvre Qt Designer et choisis un modèle de fenêtre (Main Window ou Widget).
  2. Glisse depuis la boîte de widgets les labels, la ou les zones de saisie et le bouton demandés.
  3. Modifie le texte affiché (double-clic) : par exemple « N = » ou « Vérifier ».
  4. Dans l'éditeur de propriétés, donne à chaque composant un objectName court et clair : N, Verifier, Resultat.
  5. Enregistre le fichier avec le nom demandé (par exemple Interface.ui) dans ton dossier de travail.
Attention, piège fréquent
Le nom utilisé dans le code (windows.Resultat) doit être exactement l'objectName choisi dans Qt Designer, majuscules comprises. Sinon Python affiche une erreur AttributeError.

11.3Le code de base (l'annexe du sujet)

Chaque sujet de Bac pratique fournit ce squelette en annexe. Tu dois y ajouter tes sous-programmes et ton module Play, puis remplacer les noms génériques par les tiens.

Que fait chaque ligne ?
LigneRôle
from PyQt5.uic import loadUiImporter l'outil qui charge un fichier .ui
from PyQt5.QtWidgets import QApplicationImporter la classe de l'application
app = QApplication([])Créer l'application
windows = loadUi("Interface.ui")Charger la fenêtre dessinée dans Qt Designer
windows.show()Afficher la fenêtre
windows.Verifier.clicked.connect(Play)Lancer Play à chaque clic sur le bouton Verifier
app.exec_()Démarrer la boucle d'attente des événements
Attention, piège fréquent
On écrit connect(Play) et pas connect(Play()). Avec les parenthèses, Play serait exécuté immédiatement au démarrage, avant tout clic.

À retenir

  • Qt Designer → fichier .ui ; PyQt5 → loadUi le charge.
  • text() lit (une chaîne), setText() écrit (une chaîne).
  • Play : lire → vérifier → traiter → afficher ; connect(Play) sans parenthèses.

Questions fréquentes

Comment récupérer la valeur saisie dans un QLineEdit ?
Avec la méthode text() : ch = windows.N.text(), où N est l'objectName de la zone de saisie. Le résultat est une chaîne.
Comment afficher un nombre dans un QLabel ?
setText attend une chaîne : on convertit le nombre avec str(), par exemple windows.Resultat.setText(str(s)).
Où enregistrer le fichier .ui au Bac pratique ?
Dans le dossier de travail portant ton numéro d'inscription, à côté du fichier .py. loadUi cherche le fichier dans le dossier courant, qui est celui du programme quand tu l'exécutes depuis Thonny.
