Les chaînes de caractères en algorithme et en Python

Une chaîne de caractères est une suite de caractères entre guillemets. Chaque caractère a une position, son indice, qui commence à 0. Les chaînes sont partout dans les sujets du Bac : on parcourt les chiffres d'un nombre, on teste un palindrome, on construit un message.

L'essentiel

  • ch[i] est le caractère d'indice i ; les indices vont de 0 à Long(ch) - 1.
  • Long(ch) → len(ch) ; Sous_chaine(ch, d, f) → ch[d:f].
  • + met deux chaînes bout à bout (concaténation).
  • Une chaîne Python ne se modifie pas : on en construit une nouvelle.

4.1Indices et accès aux caractères

Dans ch = "PYTHON", le caractère P a l'indice 0 et N a l'indice 5. Python accepte aussi les indices négatifs, qui partent de la fin.

Indices de la chaîne "PYTHON"
CaractèrePYTHON
Indice012345
Indice négatif-6-5-4-3-2-1
Attention, piège fréquent
Le dernier caractère est ch[len(ch) - 1]. Écrire ch[len(ch)] provoque une erreur IndexError.

À savoir
isdigit() renvoie True seulement si la chaîne n'est pas vide et ne contient que des chiffres. "-5".isdigit() et "2.5".isdigit() renvoient False.

4.3Concaténation et construction d'une chaîne

L'opérateur + colle deux chaînes. On l'utilise souvent pour construire un résultat caractère par caractère, en partant d'une chaîne vide "".

Attention, piège fréquent
Une chaîne Python est non modifiable : ch[0] = "B" provoque une erreur. Il faut construire une nouvelle chaîne : ch = "B" + ch[1:].

4.5Passer d'un nombre à une chaîne (et inversement)

Beaucoup de sujets du Bac portent sur les chiffres d'un nombre (palindrome, nombre ondulant, somme des chiffres…). Deux méthodes existent :

  • convertir en chaîne avec str(n), puis parcourir les caractères ; chaque chiffre se reconvertit avec int(ch[i]) ;
  • rester en nombres avec n % 10 (dernier chiffre) et n // 10 (on le retire).

À retenir

  • Les indices vont de 0 à len(ch) - 1.
  • Long → len, Pos → find, Sous_chaine → ch[d:f], Estnum → isdigit().
  • On ne modifie pas une chaîne : on en construit une nouvelle avec +.

Questions fréquentes

Comment obtenir la longueur d'une chaîne en Python ?
Avec la fonction len : len("Tunis") renvoie 5. Elle correspond à Long(ch) en algorithmique.
Comment traduire Sous_chaine(ch, d, f) en Python ?
Par une tranche : ch[d:f]. Le caractère d'indice f n'est pas inclus.
Comment vérifier qu'une saisie contient seulement des chiffres ?
Avec ch.isdigit(), l'équivalent de Estnum(ch). C'est la vérification la plus courante dans le module Play du Bac pratique.
