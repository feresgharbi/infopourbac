Un sous-programme est un bloc d'instructions nommé, que l'on écrit une fois et que l'on appelle autant de fois que nécessaire. Une fonction renvoie un résultat ; une procédure réalise une action sans rien renvoyer. Au Bac pratique, une solution modulaire (découpée en sous-programmes) est exigée.

L'essentiel

  • Fonction : Fonction Nom(paramètres) : Type + Retourner → def nom(paramètres): + return.
  • Procédure : Procédure Nom(paramètres) → def nom(paramètres): sans return.
  • Un paramètre précédé de @ est passé par référence : la procédure peut le modifier.
  • Les objets locaux d'un sous-programme sont déclarés dans un TDOL.

7.1Pourquoi découper en sous-programmes ?

  • Lisibilité : chaque sous-programme a un nom qui dit ce qu'il fait ;
  • Réutilisation : on écrit le code une fois, on l'appelle partout ;
  • Tests : on vérifie chaque partie séparément ;
  • Exigence du Bac : les sujets précisent qu'une solution modulaire est exigée et demandent des fonctions précises (par exemple Premier(A), Palindrome(CH), Verif(N)).

7.3La fonction booléenne

Une fonction qui répond par vrai ou faux est très fréquente au Bac (« vérifier si N est premier », « tester si CH est palindrome »).

On l'utilise directement dans une condition : if est_pair(x):.

7.4La procédure : réaliser une action

Procédure : sous-programme qui réalise une action (afficher, remplir, trier…) et ne renvoie pas de résultat.

On appelle une procédure comme une instruction, sur sa propre ligne : afficher(T, n).

7.5Paramètres formels, effectifs et mode de passage

Paramètres formels : les noms écrits dans l'en-tête du sous-programme (a, b).

Paramètres effectifs : les valeurs ou variables données au moment de l'appel (12, 15).

Passage des paramètres
ModeNotationEffetEn Python
Par valeurn : EntierLe sous-programme travaille sur une copie : la variable de l'appelant ne change pasCas des nombres, chaînes et booléens
Par référence@T : TabLe sous-programme peut modifier la variable de l'appelantCas des tableaux numpy : une modification de T[i] est visible après l'appel
À savoir
Une procédure Python ne peut pas modifier un entier reçu en paramètre. Pour « lire n » dans un sous-programme, on écrit une fonction qui renvoie la valeur : n = saisir().

7.7Objets locaux et globaux

Un objet local est créé dans un sous-programme et n'existe que pendant son exécution. Un objet global est déclaré dans le programme principal. Pour éviter les erreurs, un sous-programme doit recevoir ce dont il a besoin par ses paramètres et renvoyer son résultat avec return.

À retenir

  • Fonction = renvoie une valeur (return) ; procédure = réalise une action.
  • Les deux s'écrivent avec def en Python ; on les définit avant de les appeler.
  • @ = passage par référence ; en Python, un tableau modifié dans une procédure reste modifié.

Questions fréquentes

Quelle est la différence entre une fonction et une procédure ?
Une fonction renvoie un résultat avec return et s'utilise dans une expression. Une procédure réalise une action (afficher, remplir, trier) sans renvoyer de résultat et s'appelle comme une instruction.
Que signifie le symbole @ devant un paramètre ?
Il indique un passage par référence : le sous-programme peut modifier la variable de l'appelant. C'est le cas d'un tableau à remplir ou à trier.
Que veut dire « solution modulaire » au Bac ?
Que le programme doit être découpé en sous-programmes (fonctions et procédures), chacun responsable d'une tâche, au lieu d'un seul bloc de code.
