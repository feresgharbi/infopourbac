Une structure itérative (ou boucle) répète un bloc d'instructions. On utilise la boucle Pour quand le nombre de répétitions est connu, et les boucles Tant que ou Répéter … Jusqu'à quand il dépend d'une condition.

L'essentiel

  • Pour i de d à f Faire → for i in range(d, f + 1): (la borne f est incluse en algorithme, exclue dans range).
  • Tant que cond Faire → while cond:
  • Répéter … Jusqu'à cond n'existe pas en Python : on écrit while True: … if cond: break.
  • Somme et compteur commencent à 0, produit à 1.

6.1La boucle Pour (nombre de tours connu)

Attention, piège fréquent
En algorithmique, Pour i de 1 à 5 inclut 5. Dans range(1, 6), la borne 6 est exclue. Règle de traduction : Pour i de d à f → range(d, f + 1).
Traduire la boucle Pour avec range
AlgorithmePythonValeurs de i
Pour i de 0 à n - 1 Fairefor i in range(n):0, 1, …, n − 1
Pour i de 1 à n Fairefor i in range(1, n + 1):1, 2, …, n
Pour i de 0 à 10 (pas = 2) Fairefor i in range(0, 11, 2):0, 2, 4, 6, 8, 10
Pour i de n à 1 (pas = -1) Fairefor i in range(n, 0, -1):n, n − 1, …, 1

6.2La boucle Tant que (condition testée avant)

La condition est testée avant chaque tour. Si elle est fausse dès le départ, la boucle ne s'exécute jamais.

Attention, piège fréquent
Il faut que la condition finisse par devenir fausse. Si rien ne change dans la boucle, le programme ne s'arrête jamais : c'est une boucle infinie.

6.3La boucle Répéter … Jusqu'à (condition testée après)

Le bloc est exécuté au moins une fois, puis répété jusqu'à ce que la condition devienne vraie. Python n'a pas d'équivalent direct ; deux traductions sont possibles.

À savoir
Attention au sens : Répéter … Jusqu'à cond s'arrête quand cond est vraie, alors que while cond continue tant que cond est vraie. D'où le not dans la deuxième traduction.

6.5Compteurs et accumulateurs

Un compteur compte des événements (nb ← nb + 1). Un accumulateur cumule des valeurs (s ← s + x). Leur valeur de départ est essentielle.

Avec n = 5, on obtient s = 15 (1 + 2 + 3 + 4 + 5) et p = 120 (5!). Un produit initialisé à 0 resterait toujours égal à 0.

6.6Parcourir les chiffres d'un nombre

Le schéma « n % 10 puis n // 10 » revient dans presque tous les sujets sur les nombres.

À retenir

  • Pour i de d à f → range(d, f + 1).
  • Tant que teste avant, Répéter teste après (au moins un passage).
  • Répéter … Jusqu'à cond → while True: … if cond: break.

Questions fréquentes

Comment traduire Pour i de 1 à n en Python ?
for i in range(1, n + 1):. La fonction range exclut sa borne de fin, d'où le + 1.
Comment écrire la boucle Répéter Jusqu'à en Python ?
Python n'a pas de boucle Répéter. On utilise while True: avec un break quand la condition d'arrêt est vraie, ou une première lecture suivie de while not condition:.
Quelle est la différence entre for et while ?
for s'utilise quand on connaît le nombre de tours ; while quand on répète tant qu'une condition reste vraie, sans savoir à l'avance combien de fois.
