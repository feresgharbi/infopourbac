Une variable est un nom qui désigne une case de la mémoire contenant une valeur. Chaque valeur a un type (entier, réel, booléen, caractère, chaîne) qui détermine les opérations possibles. Au Bac, il faut connaître chaque type, chaque opérateur et leur traduction en Python.

L'essentiel

  • 5 types simples : Entier (int), Réel (float), Booléen (bool), Caractère et Chaîne (str).
  • DIV s'écrit // (quotient entier) et MOD s'écrit % (reste).
  • ET, OU, NON s'écrivent and, or, not.
  • Conversions : int(), float(), str().

3.1Variable et constante

Variable : objet dont la valeur peut changer pendant l'exécution. Elle est identifiée par un nom.

Constante : objet dont la valeur est fixée une fois pour toutes et ne change jamais.

Règles pour nommer une variable en Python : commencer par une lettre ou _, ne contenir que des lettres, des chiffres et _, pas d'espace, et éviter les mots réservés (if, for, def…). Python distingue majuscules et minuscules : Note et note sont deux variables différentes.

Python n'a pas de vraies constantes. Par convention, on écrit leur nom en majuscules :

int("abc") ou int("") provoque une erreur ValueError. Avant de convertir une saisie, vérifie qu'elle contient bien des chiffres (voir le chapitre sur les chaînes : isdigit()).

Astuce pour le Bac
MOD est l'opérateur le plus utilisé au Bac : n % 2 == 0 teste si n est pair, n % d == 0 teste si d divise n, n % 10 donne le dernier chiffre de n et n // 10 le supprime.

3.7La priorité des opérateurs

  1. les parenthèses ( ) ;
  2. la puissance ** ;
  3. *, /, //, % ;
  4. +, - ;
  5. les comparaisons ==, !=, <… ;
  6. not, puis and, puis or.

En cas de doute, ajoute des parenthèses : (a + b) / 2 n'est pas a + b / 2.

À retenir

  • Entier → int, Réel → float, Booléen → bool, Caractère et Chaîne → str.
  • DIV → //, MOD → %, ≠ → !=, ET/OU/NON → and/or/not.
  • = affecte, == compare.

Questions fréquentes

Comment écrire DIV et MOD en Python ?
DIV (quotient de la division entière) s'écrit // et MOD (reste) s'écrit %. Par exemple 17 // 5 vaut 3 et 17 % 5 vaut 2.
Comment savoir si un nombre est pair en Python ?
Un nombre n est pair si le reste de sa division par 2 est nul : n % 2 == 0.
Quelle est la différence entre / et // en Python ?
/ fait une division réelle (7 / 2 = 3.5) ; // donne le quotient entier (7 // 2 = 3).
