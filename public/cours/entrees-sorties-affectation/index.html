Tout algorithme est construit avec trois actions élémentaires : l'affectation (←, en Python =), la lecture d'une donnée (Lire, en Python input()) et l'écriture d'un résultat (Écrire, en Python print()).

L'essentiel

  • x ← 5 s'écrit x = 5 en Python : on range la valeur 5 dans la variable x.
  • Lire(x) devient x = input(), mais input() renvoie toujours une chaîne.
  • Pour lire un nombre : int(input()) (entier) ou float(input()) (réel).
  • Écrire("msg", x) devient print("msg", x).

2.1L'affectation : ranger une valeur

Affectation : action qui range une valeur dans une variable. L'ancienne valeur de la variable est remplacée.

L'affectation se lit de droite à gauche : on calcule d'abord l'expression à droite, puis on range le résultat dans la variable à gauche. C'est pour cela que x ← x * 10 a un sens : on prend l'ancienne valeur de x, on la multiplie par 10, et on range le résultat dans x.

Attention, piège fréquent
En Python, le signe = ne veut pas dire « égal » comme en mathématiques : il veut dire « reçoit ». Pour comparer deux valeurs, on utilise ==.

2.2Permuter deux variables

Échanger le contenu de deux variables est une opération classique (on la retrouve dans tous les algorithmes de tri). Il faut une variable auxiliaire, sinon une des deux valeurs est perdue.

À savoir
Python permet aussi d'écrire a, b = b, a. Au Bac, les deux écritures sont acceptées, mais la version avec aux montre que tu as compris le mécanisme.

2.4L'entrée : Lire / input

L'instruction d'entrée demande une valeur à l'utilisateur. En algorithmique on écrit souvent un message avec Écrire, puis Lire. En Python, input fait les deux à la fois.

Attention, piège fréquent
input() renvoie toujours du texte (type str). Si l'utilisateur tape 17, la variable contient la chaîne "17", et "17" + 1 provoque une erreur. Il faut convertir : int(input()) pour un entier, float(input()) pour un réel.

À retenir

  • L'affectation se lit de droite à gauche et remplace l'ancienne valeur.
  • input() renvoie toujours une chaîne : convertir avec int() ou float().
  • Pour permuter deux variables, passer par une variable auxiliaire.

Questions fréquentes

Comment lire un nombre entier en Python ?
On convertit la saisie avec int : n = int(input("n = ")). Sans int, la variable contient du texte.
Que signifie la flèche ← en algorithmique ?
C'est l'affectation : la valeur à droite est rangée dans la variable à gauche. En Python, elle s'écrit avec un seul signe égal.
Pourquoi "5" + "3" donne "53" en Python ?
Parce que ce sont deux chaînes de caractères : l'opérateur + les met bout à bout (concaténation). Avec des nombres, 5 + 3 donne 8.
