Glossaire de l'informatique au Bac

De « Accumulateur » à « Variable » : les mots du programme, expliqués simplement.

39 définitions courtes des mots de l'algorithmique et de Python que l'on rencontre dans le programme et dans les sujets du baccalauréat tunisien.

A B C D F I L M N O P Q R S T V

Accumulateur
Variable qui cumule des valeurs au fil d'une boucle (somme, produit). Une somme commence à 0, un produit à 1.
Affectation
Action qui range une valeur dans une variable : x ← 5 en algorithme, x = 5 en Python.
Algorithme
Suite finie et ordonnée d'instructions permettant de résoudre un problème.
array
Fonction de la bibliothèque numpy qui crée un tableau : T = array([int()] * n).
Booléen
Type qui ne prend que deux valeurs : Vrai/Faux (True/False en Python).
Boucle infinie
Boucle dont la condition ne devient jamais fausse : le programme ne s'arrête pas.
Chaîne de caractères
Suite de caractères entre guillemets, de type str en Python.
Compteur
Variable qui compte le nombre de fois qu'un événement se produit : nb ← nb + 1.
Concaténation
Mise bout à bout de deux chaînes avec l'opérateur +.
Constante
Objet dont la valeur ne change pas pendant l'exécution.
Dichotomie
Méthode de recherche dans un tableau trié qui divise l'intervalle de recherche par deux à chaque étape.
DIV
Opérateur du quotient de la division entière ; // en Python.
Fonction
Sous-programme qui renvoie un résultat avec Retourner (return).
Indentation
Décalage du code vers la droite (4 espaces) qui délimite les blocs en Python.
Indice
Position d'un élément dans un tableau ou une chaîne ; il commence à 0.
loadUi
Fonction de PyQt5 qui charge une interface dessinée dans Qt Designer (fichier .ui).
MOD
Opérateur du reste de la division entière ; % en Python.
Module Play
Au Bac pratique, la fonction exécutée au clic sur le bouton de l'interface.
numpy
Bibliothèque Python utilisée au Bac pour créer des tableaux avec array.
objectName
Nom donné à un composant dans Qt Designer ; c'est le nom utilisé dans le code Python.
Paramètre effectif
Valeur ou variable transmise à un sous-programme au moment de l'appel.
Paramètre formel
Nom utilisé dans l'en-tête d'un sous-programme pour désigner une donnée reçue.
Passage par référence
Mode de passage (noté @) qui permet au sous-programme de modifier la variable de l'appelant.
Passage par valeur
Mode de passage où le sous-programme travaille sur une copie de la donnée.
Permutation
Échange du contenu de deux variables, à l'aide d'une variable auxiliaire.
Procédure
Sous-programme qui réalise une action sans renvoyer de résultat.
PyQt5
Bibliothèque Python qui permet de créer et de piloter des interfaces graphiques Qt.
Qt Designer
Logiciel qui permet de dessiner une interface graphique à la souris et de l'enregistrer en fichier .ui.
range
Fonction Python qui génère une suite d'entiers pour une boucle for ; la borne de fin est exclue.
Solution modulaire
Programme découpé en sous-programmes, chacun chargé d'une tâche précise. Exigée au Bac pratique.
Sous-programme
Bloc d'instructions nommé que l'on peut appeler plusieurs fois : fonction ou procédure.
Structure conditionnelle
Structure qui exécute des instructions selon qu'une condition est vraie ou fausse (Si, Selon).
Structure itérative
Structure qui répète des instructions (Pour, Tant que, Répéter).
Tableau
Structure qui regroupe un nombre fixe d'éléments de même type, repérés par un indice.
TDNT
Tableau de déclaration des nouveaux types, où l'on définit par exemple un type tableau.
TDO
Tableau de déclaration des objets : la liste des variables et constantes d'un algorithme avec leur type.
TDOL
Tableau de déclaration des objets locaux d'un sous-programme.
Tri
Opération qui range les éléments d'un tableau dans un ordre croissant ou décroissant.
Variable
Nom désignant une case mémoire dont la valeur peut changer pendant l'exécution.
