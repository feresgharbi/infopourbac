Les algorithmes de recherche : séquentielle et dichotomique

Rechercher, c'est déterminer si une valeur x se trouve dans un tableau. La recherche séquentielle examine les éléments un par un et fonctionne sur n'importe quel tableau. La recherche dichotomique divise l'intervalle de recherche par deux à chaque étape, mais exige un tableau trié.

L'essentiel

  • Séquentielle : on avance tant que l'élément courant est différent de x.
  • Dichotomique : on compare x à l'élément du milieu et on garde la bonne moitié.
  • Sur 1 000 éléments : jusqu'à 1 000 comparaisons en séquentielle, une dizaine en dichotomique.
  • La dichotomie ne marche que sur un tableau trié.

10.1La recherche séquentielle

La boucle s'arrête soit parce que x a été trouvé (T[i] = x), soit parce qu'on a dépassé la fin du tableau (i = n). Le test final i < n distingue les deux cas.

À savoir
Pour renvoyer la position de x au lieu d'un booléen, on retourne i si i < n, et -1 sinon.

10.2La recherche dichotomique

Principe : dans un tableau trié, on compare x à l'élément du milieu. S'il est égal, c'est trouvé. Si x est plus petit, on continue dans la moitié gauche ; sinon dans la moitié droite. On s'arrête quand x est trouvé ou quand l'intervalle est vide.

Astuce pour le Bac
Si un sujet te demande de chercher plusieurs fois dans un même grand tableau, trier une fois puis utiliser la dichotomie est bien plus efficace.

10.4Rechercher dans une chaîne

Pour savoir si une chaîne en contient une autre, Python propose ch2.find(ch1) (l'équivalent de Pos(ch1, ch2)), qui renvoie la position ou -1, et l'opérateur in qui renvoie un booléen.

À retenir

  • Séquentielle : tant que i < n et T[i] != x, avancer.
  • Dichotomique : milieu (deb + fin) // 2, garder la bonne moitié ; tableau trié obligatoire.
  • La dichotomie divise le nombre de comparaisons de façon spectaculaire.

Questions fréquentes

Quelle est la condition pour utiliser la recherche dichotomique ?
Le tableau doit être trié. Sinon, comparer x à l'élément du milieu ne permet pas de savoir dans quelle moitié il se trouve.
Comment calculer le milieu en Python ?
Avec la division entière : mil = (deb + fin) // 2, qui correspond à (deb + fin) DIV 2.
Que renvoie la recherche séquentielle si la valeur est absente ?
Dans la version booléenne, elle renvoie False (la boucle s'arrête avec i = n). Dans la version qui renvoie une position, on renvoie conventionnellement -1.
