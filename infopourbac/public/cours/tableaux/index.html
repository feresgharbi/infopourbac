Un tableau (ou vecteur) est une structure qui regroupe, sous un seul nom, un nombre fixe d'éléments de même type. Chaque élément est repéré par son indice, de 0 à n − 1. Au Bac, on crée les tableaux avec la fonction array de la bibliothèque numpy.

L'essentiel

  • Déclaration : un nouveau type dans le TDNT, puis la variable dans le TDO.
  • Python : from numpy import array puis T = array([int()] * n).
  • T[i] est l'élément d'indice i ; les indices vont de 0 à n − 1.
  • Tous les éléments ont le même type.

En algorithmique, on définit d'abord un nouveau type dans le tableau de déclaration des nouveaux types (TDNT), puis on déclare la variable dans le TDO.

En Python, on crée le tableau avec array. L'expression [int()] * n fabrique une liste de n zéros, que array transforme en tableau :

Créer un tableau avec numpy
Tableau de…Création en PythonContenu initial
n entiersT = array([int()] * n)n fois 0
n réelsT = array([float()] * n)n fois 0.0
n chaînesT = array([str()] * n, dtype="U20")n chaînes vides (20 caractères max)
n booléensT = array([bool()] * n)n fois False
Attention, piège fréquent
Sans dtype, array([str()] * n) crée des cases qui ne gardent qu'un seul caractère : la chaîne "Tunis" deviendrait "T". Précise toujours une taille, par exemple dtype="U20".

Initialise le maximum avec T[0], jamais avec 0 : si toutes les valeurs sont négatives, le résultat serait faux. En Python, évite aussi de nommer une variable max, qui est le nom d'une fonction prédéfinie.

À retenir

  • Un tableau regroupe n éléments de même type, d'indices 0 à n − 1.
  • Création : from numpy import array et T = array([int()] * n).
  • Maximum et minimum : initialiser avec T[0].

Questions fréquentes

Comment créer un tableau de n entiers en Python pour le Bac ?
Avec numpy : from numpy import array, puis T = array([int()] * n). Le tableau contient n zéros.
Pourquoi utiliser numpy et non une liste Python ?
Le programme tunisien utilise des tableaux de taille fixe et d'un seul type, ce qui correspond aux tableaux numpy créés avec array. Les listes Python peuvent changer de taille et mélanger les types.
Quel est l'indice du dernier élément d'un tableau de n éléments ?
n − 1, car les indices commencent à 0.
