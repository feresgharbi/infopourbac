Les structures conditionnelles : Si, Sinon, Selon

Une structure conditionnelle permet d'exécuter des instructions seulement si une condition est vraie. Le programme officiel distingue quatre formes : Si simple, Si complète (Si…Sinon), Si généralisée (Sinon Si) et Selon. En Python, elles s'écrivent avec if, else, elif et match.

L'essentiel

  • Si … Alors … Fin Si → if condition:
  • Sinon → else: ; Sinon Si → elif condition:
  • Python termine chaque condition par deux-points et indente le bloc de 4 espaces.
  • Une seule branche est exécutée : la première dont la condition est vraie.

5.1La forme simple

Les instructions ne sont exécutées que si la condition est vraie. Sinon, on passe directement à la suite.

5.2La forme complète : Si … Sinon

À savoir
Le else n'a jamais de condition : il traite tous les autres cas.

5.3La forme généralisée : Sinon Si

Quand il y a plus de deux cas, on enchaîne les conditions. Python les teste de haut en bas et s'arrête à la première qui est vraie.

Attention, piège fréquent
L'ordre compte. Si on teste moy >= 10 en premier, une moyenne de 17 recevrait « Passable », car Python s'arrête à la première condition vraie.

5.4La structure Selon

Selon choisit un traitement d'après la valeur d'une variable. Depuis Python 3.10, on peut la traduire avec match ; avec une version plus ancienne, on utilise if … elif.

5.5Les conditions composées

On combine plusieurs conditions avec and, or et not.

Exemples de conditions composées
ConditionAlgorithmePython
n est un nombre de 3 chiffres(n ≥ 100) ET (n ≤ 999)100 <= n <= 999
n est hors de [1, 20](n < 1) OU (n > 20)n < 1 or n > 20
c est une voyellePos(c, "aeiouy") ≠ -1c in "aeiouy"
ch n'est pas numériqueNON Estnum(ch)not ch.isdigit()
Attention, piège fréquent
n > 5 or n < 10 est toujours vrai : tout nombre est soit plus grand que 5, soit plus petit que 10. Pour un intervalle, on utilise and.

5.6Les règles de syntaxe en Python

  • chaque ligne if, elif, else se termine par deux-points : ;
  • le bloc à exécuter est indenté (décalé de 4 espaces) ;
  • on compare avec ==, jamais avec = ;
  • il n'y a pas de Fin Si : le bloc se termine quand l'indentation revient à gauche.

À retenir

  • Si → if, Sinon Si → elif, Sinon → else, Selon → match ou if/elif.
  • Deux-points et indentation obligatoires.
  • Une seule branche est exécutée : la première condition vraie, de haut en bas.

Questions fréquentes

Comment traduire Sinon Si en Python ?
Avec le mot-clé elif, contraction de « else if ».
Comment traduire la structure Selon en Python ?
Avec match … case à partir de Python 3.10, ou avec une suite de if … elif … else qui fonctionne dans toutes les versions.
Pourquoi Python affiche-t-il IndentationError ?
Parce que le bloc qui suit un if, elif ou else n'est pas correctement décalé. Toutes les lignes d'un même bloc doivent avoir exactement la même indentation.
